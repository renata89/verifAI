VerifAI Architecture

AI Traceability Engine — Requirements Verifier, Test Gap Analyzer, Documentation Drift Detector

MVP — Requirements Verifier

  • • Listen to GitHub PR webhooks
  • • Parse AC from Jira/Linear tickets
  • • Analyze PR diff against AC
  • • Generate PR review comment
  • • Confidence score per AC

Phase 2 — Test Gap Analyzer

  • • Check test coverage for each AC
  • • Generate test case suggestions
  • • Acceptance + negative + edge tests
  • • Export to test framework format

Phase 3 — Documentation Drift

  • • Monitor docs vs code consistency
  • • Detect stale documentation
  • • Auto-generate PR with doc fixes
  • • README, API docs, wiki support
